Iconography

Use icons to reduce cognitive load and allow quick identification.

Variants

Outline and solid icons from heroicons are used here.

Outline

Default.

menu

Solid

Use this in buttons, form elements, to indicate action that has already taken place.

chevron-down-solid
check-circle-solid
x-circle-solid
exclamation-triangle-solid

Code

                    <mz-svg-icon key="check-circle-solid" ></mz-svg-icon>

Best practices

  • Icons should only be used when it serves a purpose and adds value.
  • Icon should reflect the associated section or action.
  • Icon should share the same color as what they're associated with.
  • The few globally recognized icons can be used by themselves to save space. Add a `sr-only` span for screen-reader in this case. See this site's hamburger menu for example.

Accessibility

Icons are rendered with aria-hidden=true. Use an additional sr-only element with help text for accessibility support.

Notes

  • Component renders via a key in icondefinitions.svg
  • To add icon to designsystem, add to `projects/components/src/assets/icons`, then run `npm run icons`
  • See icon preview page for a list of icon files shipped in package. These icons are needed by @muziehdesign/components.
  • Solidify which icon to use for info, warning, and error.

Using icons in project

Projects that consume this library can use svgo and svg-sprite to optimize and create a sprite of the icons. This can be done by using the following commands from package.json: 
         
            // package.json 
            "icons": "npm run icons:optimize && npm run icons:sprite", 
            "icons:optimize": "svgo --config .svgo.js src/assets/icons", 
            "icons:sprite": "svg-sprite --config ./.svg-sprite.json node_modules/@muziehdesign/components/assets/icons/*.svg src/assets/icons/*.svg"
  • Place new icon file in `src/assets/icons`. File name should be all lowercase and follow pattern of `[kebab-case-name]-[iconType (solid | outline)]`
  • Run `npm run icons`
  • Verify icons in `/assets/icondefinitions.html` 
                        @component({ imports: [ SvgIconComponent ] ... })
                    <mz-svg-icon key="menu-outline"></mz-svg-icon>
Remember to remove icondefinitions.html from build process for production if you don't want to ship it. See `src/.svg-sprite.json` and `.svgo.js` for configuration examples.
